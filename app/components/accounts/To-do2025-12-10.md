## 📝 Notes importantes

### **Point clé 1 : Relation Membre ↔ Compte**
```
1 Membre → N Comptes
- À la création d'un membre → 1 compte par défaut est créé automatiquement
- Un membre peut avoir plusieurs comptes (Épargne + Chèques + Terme)
- Chaque compte a un `id_membre` qui lie au membre
```

### **Point clé 2 : Mode CREATE vs EDIT**
```typescript
// Dans EditAccountModal.tsx
const isEditMode = !!account;  // true si account existe

if (isEditMode) {
  // PATCH /api/accounts/{account.id}/
  // Champs protégés désactivés
} else {
  // POST /api/accounts/
  // Tous les champs actifs
}
```

### **Point clé 3 : Numéro de compte**
```
❌ PAS généré par le frontend
✅ Généré par le backend lors du POST
Backend retourne: { "noCompte": "EPG-00001234", ... }
```
